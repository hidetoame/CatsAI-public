# Privacy Policy for CatsAI

Last updated: May 21, 2026

CatsAI is a desktop voice assistant application for macOS.

## Information the app uses

CatsAI may use the following information only when the user enables the related feature:

- Microphone audio, to send voice input to OpenAI Realtime API
- Screen image, to understand the visible screen when the user asks the app to look at it
- Google Calendar data, to check calendar events and add calendar events when the user enables Google Calendar integration
- Email account connection settings, to check matching email headers when the user enables email check
- Local files or folders, only when the user asks CatsAI to open, create, search, move, or trash them and has enabled the related feature

## Google Calendar data

When Google Calendar integration is enabled, CatsAI requests access to Google Calendar in order to:

- Read calendar events for schedule confirmation
- Add calendar events when the user asks CatsAI to create a schedule

CatsAI does not sell Google user data. CatsAI does not use Google Calendar data for advertising. CatsAI only uses Google Calendar data to provide the calendar features requested by the user.

## Storage

CatsAI stores configuration locally on the user's Mac. This may include API keys, Google OAuth tokens, mail connection settings, and app preferences. These are stored locally for personal use by the app.

## Data sharing

CatsAI sends user requests to external services only when required for the enabled feature, including OpenAI APIs and Google APIs. CatsAI does not operate a separate server to collect user data.

## User control

Users can disable Google Calendar integration in the app settings. Users can also revoke Google access from their Google Account permissions page.

Google Account permissions: https://myaccount.google.com/permissions
